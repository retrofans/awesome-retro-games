# Awesome Retro Games [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of classic retro games resources: play in your browser, pick an emulator, find game history, and make your own homebrew.

Retro gaming covers everything from 8-bit consoles to early 3D systems. This list collects the places worth bookmarking, whether you want to jump into a game in seconds or dig into how a console works.

## Play in Your Browser

- [EmuAll](https://emuall.com) - Play classic games in your browser on 18 platforms, no install needed.
- [EmulatorJS](https://emulatorjs.org) - Open-source project for embedding retro emulators in web pages.
- [js-dos](https://js-dos.com) - Run DOS games and programs in the browser.
- [Internet Arcade](https://archive.org/details/internetarcade) - Browser-playable classic arcade machines from the Internet Archive.
- [Console Living Room](https://archive.org/details/consolelivingroom) - Console games playable in the browser from the Internet Archive.

## Emulators

Multi-system

- [RetroArch](https://www.retroarch.com) - Front end for the Libretro API that runs cores for dozens of systems.
- [Mednafen](https://mednafen.github.io) - Multi-system emulator focused on accuracy.
- [Ares](https://ares-emu.net) - Cycle-accurate multi-system emulator.

Nintendo

- [Mesen](https://www.mesen.ca) - Accurate NES, SNES, Game Boy and more, with strong debugging tools.
- [Snes9x](https://www.snes9x.com) - Fast, portable SNES emulator.
- [bsnes](https://github.com/bsnes-emu/bsnes) - Accuracy-first SNES emulator.
- [mGBA](https://mgba.io) - Game Boy, Game Boy Color and Game Boy Advance emulator.
- [melonDS](https://melonds.kuribo64.net) - Nintendo DS emulator.
- [DeSmuME](https://desmume.org) - Nintendo DS emulator.
- [Mupen64Plus](https://mupen64plus.org) - Cross-platform Nintendo 64 emulator.
- [Project64](https://www.pj64-emu.com) - Nintendo 64 emulator for Windows.
- [Dolphin](https://dolphin-emu.org) - GameCube and Wii emulator.
- [Azahar](https://github.com/azahar-emu/azahar) - Nintendo 3DS emulator.

Sega

- [Genesis Plus GX](https://github.com/ekeeke/Genesis-Plus-GX) - Master System, Game Gear, Mega Drive and Sega CD.
- [BlastEm](https://www.retrodev.com/blastem/) - Accurate Mega Drive / Genesis emulator.
- [Flycast](https://github.com/flyinghead/flycast) - Dreamcast and Naomi emulator.

Sony

- [DuckStation](https://github.com/stenzek/duckstation) - PlayStation 1 emulator.
- [PPSSPP](https://www.ppsspp.org) - PSP emulator.

Arcade

- [MAME](https://www.mamedev.org) - The reference arcade emulator and hardware documentation project.
- [FBNeo](https://github.com/finalburnneo/FBNeo) - Arcade emulator focused on Capcom, Neo Geo and other classic boards.

## Frontends and Retro OS

- [EmulationStation Desktop Edition](https://es-de.org) - Game library frontend for desktop and handheld devices.
- [Batocera](https://batocera.org) - Retro gaming operating system you boot from a USB stick or SD card.
- [Lakka](https://www.lakka.tv) - Lightweight Linux distribution built around RetroArch.
- [RetroPie](https://retropie.org.uk) - Turn a Raspberry Pi into a retro gaming machine.
- [OpenEmu](https://openemu.org) - Multi-system emulator front end for macOS.
- [Pegasus Frontend](https://pegasus-frontend.org) - Customizable cross-platform game launcher.
- [LaunchBox](https://www.launchbox-app.com) - Game library manager with metadata and artwork.

## Preservation and Databases

- [Internet Archive Software Library](https://archive.org/details/softwarelibrary) - Historical software collections.
- [No-Intro](https://no-intro.org) - Cartridge dump verification and naming database.
- [Redump](http://redump.org) - Disc dump verification database.
- [Video Game History Foundation](https://gamehistory.org) - Nonprofit dedicated to preserving video game history.
- [The Strong National Museum of Play](https://www.museumofplay.org) - Museum with one of the largest video game collections.
- [MobyGames](https://www.mobygames.com) - Credits, release dates and screenshots for games across platforms.
- [RetroAchievements](https://retroachievements.org) - Achievements for classic games running in supported emulators.

## Game History and Guides

- [The Cutting Room Floor](https://tcrf.net) - Unused and cut content found in games.
- [Hardcore Gaming 101](http://www.hardcoregaming101.net) - In-depth articles on classic and obscure games.
- [GameFAQs](https://gamefaqs.gamespot.com) - Walkthroughs, FAQs and cheats.
- [Speedrun.com](https://www.speedrun.com) - Leaderboards and records for speedrunners.
- [Retro Game Mechanics Explained](https://www.youtube.com/@RGMechEx) - Video series on how classic console hardware works.
- [Emulation General Wiki](https://emulation.gametechwiki.com) - Guides and comparisons for emulators on every platform.

## Homebrew and Development

- [Homebrew Hub](https://hh.gbdev.io) - Catalog of Game Boy and Game Boy Color homebrew.
- [GB Studio](https://www.gbstudio.dev) - Drag-and-drop game maker for Game Boy.
- [GBDK-2020](https://github.com/gbdk-2020/gbdk-2020) - C development kit for Game Boy and Game Gear.
- [NESdev Wiki](https://www.nesdev.org/wiki/Nesdev_Wiki) - Technical documentation for NES and Famicom development.
- [SGDK](https://github.com/Stephane-D/SGDK) - Development kit for Mega Drive / Genesis.
- [devkitPro](https://devkitpro.org) - Toolchains for Nintendo consoles and handhelds.
- [PICO-8](https://www.lexaloffle.com/pico-8.php) - Fantasy console with a retro look and built-in tools.

## Open Source Engines

- [ScummVM](https://www.scummvm.org) - Run classic point-and-click adventures on modern systems.
- [DOSBox Staging](https://www.dosbox-staging.org) - Modernized DOSBox for DOS games.
- [DOSBox-X](https://dosbox-x.com) - DOSBox fork with broader hardware and PC-98 support.
- [OpenTTD](https://www.openttd.org) - Open-source remake of Transport Tycoon Deluxe.
- [OpenRA](https://www.openra.net) - Modern engine for classic real-time strategy games.

## Contributing

Pull requests are welcome. Before you open one:

- Use the format `[Name](link) - One sentence describing what it is.` and end with a period.
- Only add active, useful resources that you have checked yourself.
- One resource per pull request, with a short note on why it belongs.

Emulators are legal software. Game files are protected by copyright in most countries, so only play games you are entitled to.
